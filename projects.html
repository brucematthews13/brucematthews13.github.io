Sequel Tea — Business Analytics & Dashboard

Systems Optimization Club (Cal Poly SLO) · Project Lead · Team of 5

Sequel Tea, a boba tea shop launching a new on-campus store, needed a way to actually see how the business was performing — instead of retyping sales numbers into spreadsheets by hand every day. I led a 5-person student consulting team to design and build a live analytics dashboard that pulls directly from the store's point-of-sale systems.

The problem

Sales and financial data came from two disconnected sources — Grubhub (online orders) and Micros (in-store POS) — and had to be manually entered and charted, taking roughly 10 minutes per update with limited, inconsistent visuals and no automated reporting.

What I built (with my team)

As project lead and primary client contact, I coordinated requirements gathering and stakeholder meetings with Sequel Tea, then directed the design of:

  • An automated ETL data pipeline (Google Apps Script) that detects, parses, and loads Grubhub and Micros CSV exports every night — with error handling that routes bad files to a review folder instead of silently failing.
  • Three live Google Data Studio dashboards: Sales (channel mix, daily/weekly trends, category breakdowns), Financial (revenue, COGS %, labor %, revenue per labor hour), and Inventory (ingredient usage, week-over-week comparisons, restocking signals).
  • A COGS and ingredient-consumption calculator that derives material costs and usage straight from sales data and recipes, instead of requiring manual tracking.
  • A 25-page user guide documenting how to operate, maintain, and troubleshoot the entire system for non-technical staff.

Results

98%reduction in data-processing time
~10 secvs. ~10 min manual entry, per update
3live dashboards shipped (sales, financial, inventory)
“More than just a time difference, because the data in those 10 minutes is nowhere near as comprehensive.” — Justin Chan, Sequel Tea

Beyond the time savings, the dashboards gave ownership faster access to decision-relevant metrics for staffing, inventory, and pricing, and set up the data pipeline to scale as Sequel Tea expands to new locations.

What I learned

Scoping a project so it stays achievable and genuinely useful matters more than adding features; tailoring technical explanations to a non-technical audience (and scheduling regular client check-ins) made the difference between a dashboard that looked good and one the client actually adopted.

Tools: Google Data Studio · Google Sheets · Apps Script (JavaScript) · Grubhub & Micros POS data

Basketball Recruiting Decision Tool (AHP)

Operations Research (IME 305) · Cal Poly SLO · Team Final Project

Built a decision-support tool for a team final project: a coaching staff describes the kind of player they need — position, scenario, and which traits matter most — and the model returns a ranked list of the best-fit candidates from a pool of real Division I players.

The method

The core challenge is that "what makes a good fit" is subjective and multi-dimensional — a team needing a rebounder values different things than one needing a scorer. We used the Analytical Hierarchy Process (AHP) to turn those subjective priorities into objective numeric weights, using pairwise comparison matrices (Saaty's 1–9 preference scale) across six criteria: scoring efficiency, offensive impact, rebounding, defensive impact, basketball IQ, and physical profile.

What the model does

  • Pulls real season and combine data for ~78 Division I players — shooting efficiency, plus/minus, rebound rate, steal % + block %, assist/turnover ratio, and physical measurables like vertical leap and lane agility time.
  • Normalizes every metric onto a common 0–1 scale (using each metric's max/min/span) so stats with completely different units can be fairly compared side by side.
  • Combines the normalized player data with the AHP-derived criteria weights to compute a single composite fit score per player.
  • Ranks all candidates by that score and surfaces the top matches for the specified positional need and scenario.

Beyond basketball, this is the same structure used for real business decisions with competing, hard-to-compare criteria — vendor selection, hiring, or sourcing decisions — which is why AHP is a standard operations research and consulting tool, not just a sports analytics one.

Tools: Microsoft Excel (AHP pairwise weighting, data normalization, composite scoring)

5S Process Improvement Project

Cal Poly SLO · Team Project · 11/2025

Applied the 5S methodology (Sort, Set in Order, Shine, Standardize, Sustain) to analyze and redesign Cal Poly's university housing room-change process, run through the StarRez housing platform.

The problem

Housing staff had to manually pull availability reports out of StarRez, clean and sort the data in Excel, and hand-compare it against each student's room preferences before approving a change — a slow, fully manual matching process with no automation.

Recommendations by category

  • Sort: use StarRez's built-in Auto-Allocate feature to automatically match available rooms against student-requested rooms/buildings, removing the need to manually cross-reference spreadsheets.
  • Set in Order: add an automated notification/email step so staff are alerted exactly when a request needs their action, on top of StarRez's existing status-tracking tabs.
  • Shine: keep submitted requests moved into "offered" status on a fixed weekly cadence, so the queue stays clean before the next round of changes is processed.
  • Standardize: formalize the already-consistent weekly process into a documented schedule of roles and responsibilities.
  • Sustain: post visual workflow references and build a standardized training path for new staff, so the process holds up as people rotate through the role.

We benchmarked the recommendation against real hospitality-industry 5S rollouts — including a resort that used 5S to shorten housekeeping turnover times and a hotel that cut room-cleaning time by 40% — to ground the proposal in results other organizations had actually achieved with the same methodology.
