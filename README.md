# Bruce Matthews — Portfolio Site

Personal portfolio website, built as a static multi-page HTML/CSS site (no build tools required) so it can be hosted for free with GitHub Pages.

## Pages
- `index.html` — Home / About
- `experience.html` — Work experience & leadership
- `projects.html` — Project case studies (Sequel Tea dashboard, 5S project, engineering builds)
- `skills.html` — Skills & tools
- `resume.html` — Resume summary + PDF download
- `contact.html` — Contact info
- `resume.pdf` — Downloadable résumé
- `style.css` — Shared styling

## Updating this site
Edit any `.html` file directly (they're plain text), then re-upload the changed file(s) to this repository — GitHub Pages will automatically redeploy within a minute or two.

## Live site
Once GitHub Pages is enabled on this repo, the site is live at:
`https://<your-github-username>.github.io`
